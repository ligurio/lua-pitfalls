---
layout: pitfall
title: "Using box.* before box.cfg() fails"
permalink: /t/T1001/
description: >-
  The Tarantool database API (`box.space`, `box.index`, `box.error`, ...) is
  unusable until the server is initialized with `box.cfg{}`. Accessing it
  earlier raises "Please call box.cfg() first", even though the Lua runtime
  itself already works.
platform:
  - Tarantool
runtime:
  - Lua 5.1
---

```lua
-- Accessing the database before initialization:
local space = box.space.users
-- Runtime error: Please call box.cfg() first
```

Call `box.cfg{}` once, before touching any `box.*` API:

```lua
box.cfg{listen = 3301}

local space = box.space.users   -- works now
```
