---
layout: pitfall
title: "Magic characters must be escaped in patterns"
permalink: /p/L1013/
description: >-
  `string.find`, `string.match` and `string.gsub` use Lua patterns in which
  `^$()%.[]*+-?` are magic characters. Searching for one of them literally
  requires escaping with `%`, otherwise a malformed pattern error is raised.
runtime:
  - Lua 5.1
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
  - LuaJIT
---

```lua
local s = "price (USD)"

print(string.find(s, "("))
-- Runtime error: malformed pattern (missing '[')

-- Escape the magic character:
print(string.find(s, "%("))   -- 7 7
```

To match an arbitrary user input, escape every magic character first:
`local pat = (input:gsub("[%^%$%(%)%%%.%[%]%*%+%-%?]", "%%%0"))`.
