---
layout: pitfall
title: "string.format() %d requires an integer"
permalink: /p/L1016/
description: >-
  On Lua 5.3+ the `%d` conversion expects an integer. Passing a float with a
  fractional part raises a runtime error instead of truncating, which is what
  Lua 5.1 and LuaJIT did. Use `%f` or convert with `//` first.
runtime:
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
analyzers:
  - emmylua-analyzer
---

```lua
local x = 2.5

print(string.format("%d", x))
-- Lua 5.1 / LuaJIT: prints "2"
-- Lua 5.3+: Runtime error: bad argument #2 to 'format'
--            (number has no integer representation)

print(string.format("%.0f", x))    -- "2"
print(string.format("%d", x // 1))  -- "2"
```

To stay portable, only pass integers (or integer-valued floats) to `%d`.
