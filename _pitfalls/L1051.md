---
layout: pitfall
title: "math.random() without a seed repeats the same sequence"
permalink: /p/L1051/
description: >-
  The pseudo-random generator starts from a fixed state, so without a call to
  `math.randomseed` every run produces the exact same numbers. Call
  `math.randomseed(os.time())` once at startup.
runtime:
  - Lua 5.1
  - Lua 5.2
  - Lua 5.3
  - LuaJIT
analyzers:
  - semgrep
---

```lua
print(math.random(1, 100))
print(math.random(1, 100))
-- The same two numbers on every run of the program.
```

Seed the generator once, at the start of the program:

```lua
math.randomseed(os.time())
print(math.random(1, 100))
```

Notes per version:

- Lua 5.1: `math.randomseed()` with no argument seeds with a fixed value, so it
  does not help; pass an integer such as `os.time()`.
- Lua 5.2 and 5.3: `math.random` accepts integer bounds only and still needs an
  explicit seed.
- Lua 5.4 and 5.5: the generator is seeded from a random source at startup and
  `math.randomseed` exists mainly to make sequences reproducible.

For anything security-sensitive do not use `math.random` at all; it is a fast
non-cryptographic generator.
