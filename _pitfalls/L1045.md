---
layout: pitfall
title: "A numeric for that counts down needs an explicit negative step"
permalink: /p/L1045/
description: >-
  The default step of a numeric `for` is `+1`, so `for i = #t, 1 do` runs zero
  times: the start value is already greater than the limit. Iterating backwards
  requires `-1` as the third expression.
runtime:
  - Lua 5.1
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
  - LuaJIT
analyzers:
  - semgrep
---

```lua
local t = {"a", "b", "c"}

for i = #t, 1 do
  print(t[i])
end
-- prints nothing: with the default step +1 the loop condition
-- "from #t down to 1" is already false
```

Pass `-1` to make the loop count down:

```lua
for i = #t, 1, -1 do
  print(t[i])            -- c, b, a
end
```

A step of `0` is rejected at runtime with "'for' step is zero", and a loop whose
step points away from the limit also runs zero times.
