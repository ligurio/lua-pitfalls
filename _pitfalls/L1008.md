---
layout: pitfall
title: "Integers wrap around on overflow"
permalink: /p/L1008/
description: >-
  Lua 5.3+ integers are signed 64-bit. Arithmetic that overflows wraps
  silently to the other end of the range instead of raising an error or
  promoting to a float, so `math.maxinteger + 1` equals `math.mininteger`.
runtime:
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
---

```lua
local m = math.maxinteger   -- 9223372036854775807

print(m + 1)                          -- -9223372036854775808
print(m + 1 == math.mininteger)       --> true
print(m + 1 == m + 0.0 + 1)           --> false (floats do not wrap)
```

Guard arithmetic that can exceed the range, e.g. by comparing with
`math.maxinteger`/`math.mininteger` before adding, or by forcing float
arithmetic when precision loss is acceptable.
