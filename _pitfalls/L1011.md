---
layout: pitfall
title: "Only false and nil are falsy"
permalink: /p/L1011/
description: >-
  Unlike C, `0` and the empty string are truthy in Lua. Only `false` and `nil`
  fail a boolean test, so guards written with C-style expectations behave
  unexpectedly.
runtime:
  - Lua 5.1
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
  - LuaJIT
---

```lua
if 0 then
  print("0 is truthy")
end

if "" then
  print("empty string is truthy")
end

if nil then
  print("never printed")
end
```

Check explicitly for the value you care about, e.g. `if x ~= 0 then` or
`if x ~= nil and x ~= "" then`.
