title: "Duplicate keys in a table constructor"
permalink: /p/L1055/
description: >-
  When the same key appears twice in a table constructor the last assignment
  wins and the earlier value is silently lost. It is almost always a copy-paste
  mistake, because the two fields look identical in the source.
runtime:
  - Lua 5.1
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
  - LuaJIT
analyzers:
  - semgrep
  - luacheck
  - emmylua-analyzer
---

```lua
local config = {
  first = 1,
  second = 2,
  first = 3,       -- overwrites first = 1
}

print(config.first)   -- 3
print(config.second)  -- 2
```

Remove the duplicate or give the fields distinct names:

```lua
local config = {
  first = 1,
  second = 2,
  third = 3,
}
```

The same applies to a mix of explicit keys and array items that resolve to the
same index, for example `{ [1] = "a", "b" }`, where the positional item also
occupies index 1.
