---
layout: pitfall
title: "Division always returns a float; use // for integer division"
permalink: /p/L1007/
description: >-
  Since Lua 5.3 the division operator always yields a float, even when both
  operands are integers. Use `//` (floor division) to get an integer back;
  otherwise a float result can break indexing, `%d` formatting and equality
  checks.
runtime:
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
---

```lua
local a, b = 7, 2

print(a / b)   -- 3.5
print(a // b)  -- 3

local t = {"x", "y", "z"}
print(t[a / b])   -- nil: 3.5 is a float key, not t[3]
print(t[a // b])  -- "z"
```

Code written for Lua 5.2 (where `/` on integers returned an integer) needs
`math.floor(a / b)` or `a // b` to keep the old behaviour on 5.3+.
