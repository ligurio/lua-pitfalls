title: "Function calls may omit parentheses, and a leading '(' continues the previous line"
permalink: /p/L1097/
description: >-
  A call whose only argument is a string or table literal can drop the
  parentheses: `f "x"`, `f {}`, `f [[x]]`. The same grammar treats a `(` at the
  start of a line as a continuation of the expression above it, so a
  parenthesized statement can be silently swallowed as an argument.
runtime:
  - Lua 5.1
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
  - LuaJIT
---

```lua
local function f(x) print(type(x), x) end

f "hello"       -- string  hello
f {1, 2}        -- table   table: 0x...
f [[text]]      -- string  text
```

The literal must be the *only* argument, and the function name and the literal
may sit on different lines - the call still happens:

```lua
f
"next line"     -- string  next line: still a call to f

f "a", "b"      -- Syntax error: unexpected symbol near ','
```

Because this spelling is legal, anything that scans for `name(` - a linter, a
security rule, a grep - will miss `require "mod"`, `dofile "config.lua"` and
`os.execute "ls"`.

The same rule makes a parenthesized expression at the start of a line continue
the previous statement instead of beginning a new one:

```lua
local function f(x) return x end

local a = f

(f)("ignored")

print(type(a))  -- Lua 5.1/LuaJIT: syntax error "ambiguous syntax"
                -- Lua 5.2+: "string"; a is now "ignored", not f
```

With no parentheses of its own, `(f)("ignored")` is parsed as
`local a = f(f)("ignored")`: `f(f)` returns `f`, then `f("ignored")` returns the
string, which becomes the value of `a`. The blank line changes nothing - the
parser skips whitespace before deciding. Lua 5.1 and LuaJIT refuse to guess and
raise `ambiguous syntax (function call x new statement)`, while Lua 5.2 and
later quietly commit to the call.

Terminate the statement that precedes the parenthesis, or do not start a line
with `(`:

```lua
local a = f;    -- semicolon ends the statement
(f)("ignored")

print(type(a))  -- function, as intended
```
