---
layout: pitfall
title: "Integer division or modulo by zero raises an error"
permalink: /p/L1034/
description: >-
  Floating-point division by zero yields `inf`, but integer `//` and `%` by
  zero are errors in Lua 5.3+. Code that relies on `x / y` returning `inf`
  breaks when it is rewritten with `//`, and `1 % 0` raises instead of
  returning a value.
runtime:
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
---

```lua
print(1 / 0)    -- inf, no error

print(1 // 0)
-- Runtime error: attempt to divide by zero

print(1 % 0)
-- Runtime error: attempt to perform 'n%0'
```

`/` always produces a float, so dividing by zero follows IEEE 754 and yields
`inf` (`nan` for `0 / 0`). The integer operators `//` and `%` have no such
value and raise an error instead.

On Lua 5.1, Lua 5.2 and LuaJIT there are no distinct integer values: `1 / 0`
is `inf` and `1 % 0` returns `nan` without raising. See also
[L1007]({{ '/p/L1007/' | relative_url }}) and
[L1033]({{ '/p/L1033/' | relative_url }}).
