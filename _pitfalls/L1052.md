---
layout: pitfall
title: "Unbalanced assignment fills missing values with nil"
permalink: /p/L1052/
description: >-
  In `local x, y, z = 1, 2` there are fewer values than variables, so `z` is set
  to `nil`. The same happens when a function returns fewer values than the
  number of variables it is assigned to. Extra values on the right are simply
  discarded.
runtime:
  - Lua 5.1
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
  - LuaJIT
analyzers:
  - semgrep
  - luacheck
---

```lua
local x, y, z = 1, 2
print(z)               -- nil

local function pair()
  return 1, 2
end

local a, b, c = pair()
print(c)               -- nil, the function only returns two values
```

Balance the number of values on both sides, or make the missing value explicit
so the intent is visible:

```lua
local x, y, z = 1, 2, 3

local a, b, c = pair(), nil   -- still nil, but now on purpose
```

The reverse case, `local x = 1, 2, 3`, silently discards `2` and `3`. A linter
reports both directions.
