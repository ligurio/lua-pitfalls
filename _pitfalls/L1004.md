---
layout: pitfall
title: "The length operator is undefined for tables with holes"
permalink: /p/L1004/
description: >-
  For arrays with nil holes (sparse arrays), the result of `#t` is only
  guaranteed to be a border. In practice it may return 0 or an arbitrary
  index, and the answer can differ between implementations, so `#t` cannot
  be trusted to count elements.
runtime:
  - Lua 5.1
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
  - LuaJIT
---

```lua
local t = {1, nil, 3, 4}

-- Undefined for tables with holes:
print(#t)  -- may be 1, 3 or 4 depending on the implementation

-- The loop may stop at 1, silently skipping 3 and 4:
for i = 1, #t do
  print(i, t[i])
end
```

If the array is not dense, keep the length explicitly or iterate with
`pairs()`/`next()` and count only the values you care about.
