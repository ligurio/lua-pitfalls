---
layout: pitfall
title: "table.maxn(), table.foreach() and table.foreachi() removed in Lua 5.2"
permalink: /p/L1023/
description: >-
  Lua 5.1 had `table.maxn()`, `table.foreach()` and `table.foreachi()` for
  working with the array part of a table. They were removed in Lua 5.2. Use `#`
  for dense arrays and `pairs()` or `ipairs()` to iterate; for sparse tables
  write the maxn logic yourself with a loop.
runtime:
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
analyzers:
  - luacheck
  - selene
---

```lua
local t = {10, 20, 30}

print(table.maxn(t))        -- 3 (Lua 5.1 only)
table.foreach(t, function(k, v) print(k, v) end)    -- 5.1 only
table.foreachi(t, function(i, v) print(i, v) end)   -- 5.1 only
```

```lua
-- Lua 5.2+: attempt to call field 'maxn' (a nil value)
```

Portable forms:

```lua
local t = {10, 20, 30}

print(#t)   -- 3, for dense arrays

for k, v in pairs(t) do    -- visits every key
  print(k, v)
end

for i, v in ipairs(t) do   -- visits indices 1..#t
  print(i, v)
end
```

`#t` is only trustworthy for dense arrays; see
[L1004]({{ '/p/L1004/' | relative_url }}). `luacheck` and `selene` flag
`table.maxn`/`table.foreach`/`table.foreachi` as undefined fields when
targeting 5.2+.
