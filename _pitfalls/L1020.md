---
layout: pitfall
title: "String concatenation in a loop is quadratic"
permalink: /p/L1020/
description: >-
  Strings in Lua are immutable, so every `result = result .. "word"` allocates
  a new string and copies the whole accumulated buffer. Building a string with
  repeated concatenation in a loop is quadratic in the number of parts and
  gets noticeably slow for large inputs. Collect the parts in a table and join
  them once with `table.concat()`.
runtime:
  - Lua 5.1
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
  - LuaJIT
---

```lua
local result = ""
for i = 1, 1000 do
  result = result .. "word"   -- allocates and copies the whole string each time
end
```

Because strings are immutable, every iteration allocates a brand new string
and copies everything accumulated so far, so the total work is quadratic in
the number of parts. Collect the parts first and join them once:

```lua
local words = {}
for i = 1, 1000 do
  table.insert(words, "word")
end
local result = table.concat(words)
```

`table.concat()` also accepts a separator as its second argument, e.g.
`table.concat(words, " ")`. This is a performance issue rather than a
correctness one, so no static analyzer flags it. Note that the parts must be
strings; see [L1009]({{ '/p/L1009/' | relative_url }}).
