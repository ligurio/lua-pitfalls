---
layout: pitfall
title: "`==` compares tables by reference, not contents"
permalink: /p/L1010/
description: >-
  Two structurally identical tables are different objects, so `==` returns
  false for them. Comparing table contents requires an explicit deep-equality
  function; the built-in operator only compares references.
runtime:
  - Lua 5.1
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
  - LuaJIT
analyzers:
  - emmylua-analyzer
---

```lua
local a = {1, 2, 3}
local b = {1, 2, 3}

print(a == b)   --> false
print(a == a)   --> true

local c = a
print(a == c)   --> true: the same reference
```

Unless a `__eq` metamethod is installed, table equality is reference
equality. Write a recursive comparison if you need value equality.
