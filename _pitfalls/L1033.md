---
layout: pitfall
title: "Floor division and modulo round toward negative infinity"
permalink: /p/L1033/
description: >-
  Lua's integer division `//` floors the result, and `%` is defined as
  `a - (a // b) * b`, so both round toward negative infinity. For negative
  operands this differs from C (which truncates toward zero): `-7 // 2` is
  `-4`, and the sign of `a % b` follows the divisor.
runtime:
  - Lua 5.1
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
  - LuaJIT
---

```lua
print(-7 // 2)   -- -4, not -3
print(-7 % 2)    --  1, not -1
print(7 % -2)    -- -1
print(7 // -2)   -- -4
```

Because `%` is derived from floor division, its result takes the sign of the
divisor rather than the dividend. Code ported from C or another language that
truncates toward zero silently produces different remainders (and therefore
different indexes and hash buckets) for negative values.

```lua
print(math.fmod(-7, 2))   -- -1: truncates toward zero, like C
```

`//` was added in Lua 5.3, while the floor semantics of `%` apply to every
version. See also [L1007]({{ '/p/L1007/' | relative_url }}) and
[L1034]({{ '/p/L1034/' | relative_url }}).
