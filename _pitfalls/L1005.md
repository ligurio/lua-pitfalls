---
layout: pitfall
title: "ipairs() stops at the first nil"
permalink: /p/L1005/
description: >-
  `ipairs()` only walks the contiguous run of elements starting at index 1. The
  first nil value ends the iteration, so every element after a hole in the
  array is silently never visited.
runtime:
  - Lua 5.1
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
  - LuaJIT
---

```lua
local t = {1, nil, 3}

for i, v in ipairs(t) do
  print(i, v)
end
-- Prints "1 1" and stops: the value 3 is never visited.
```

Use `pairs()` (order not guaranteed) or an explicit numeric loop if the array
may contain holes.
