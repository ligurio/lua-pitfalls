---
layout: pitfall
title: "bit32 library removed in Lua 5.4"
permalink: /p/L1026/
description: >-
  The `bit32` library (introduced in Lua 5.2, deprecated in 5.3) was removed in
  Lua 5.4. It operated on 32-bit integers. Replace its functions with the
  bitwise operators `&`, `|`, `~`, `<<` and `>>`, which work on full Lua
  integers (64-bit by default).
runtime:
  - Lua 5.4
  - Lua 5.5
analyzers:
  - luacheck
  - selene
---

```lua
-- Lua 5.2 / 5.3:
local x = bit32.band(12, 10)   -- 8 (1100 & 1010)
local y = bit32.lshift(1, 8)   -- 256
```

```lua
-- Lua 5.4+: attempt to index global 'bit32' (a nil value)
local x = bit32.band(12, 10)
```

Lua 5.3+ equivalents:

```lua
local x = 12 & 10   -- 8
local y = 1 << 8    -- 256
```

`luacheck` and `selene` flag `bit32` as an undefined global when targeting
5.4+. Note that `bit32` truncated values to 32 bits, while the bitwise
operators operate on the full Lua integer (64-bit by default).
