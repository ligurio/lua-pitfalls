---
layout: pitfall
title: "module() and package.seeall() removed in Lua 5.2"
permalink: /p/L1022/
description: >-
  Lua 5.1 provided `module()` to define modules and `package.seeall()` to give
  a module access to the global environment. Both were removed in Lua 5.2:
  calling `module()` now raises "attempt to call global 'module' (a nil
  value)". Write modules as regular files that return a table, and let
  `require()` handle loading.
runtime:
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
analyzers:
  - luacheck
  - selene
---

```lua
-- Lua 5.1 style:
module("mymod", package.seeall)

function mymod.hello()
  print("hi")
end
```

```lua
-- Lua 5.2+: attempt to call global 'module' (a nil value)
module("mymod", package.seeall)
```

Use a plain module file that returns a table:

```lua
-- mymod.lua
local M = {}

function M.hello()
  print("hi")
end

return M
```

```lua
-- caller.lua
local mymod = require("mymod")
mymod.hello()
```

`luacheck` and `selene` flag `module()` as an undefined global when targeting
5.2+. See also [L1014]({{ '/p/L1014/' | relative_url }}).
