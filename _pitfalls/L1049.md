---
layout: pitfall
title: "print() on a table or function prints an address, not its contents"
permalink: /p/L1049/
description: >-
  `print` converts each argument with `tostring`, which falls back to a generic
  "table: 0x..." / "function: 0x..." representation. Printing a table therefore
  shows an address, which is useless for debugging and different on every run.
runtime:
  - Lua 5.1
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
  - LuaJIT
analyzers:
  - semgrep
---

```lua
local point = { x = 1, y = 2 }

print(point)
-- table: 0x55d3f0a1c2b0 (the address, not the fields)
```

Use an explicit serializer, or give the value a `__tostring` metamethod:

```lua
local function dump(value)
  if type(value) ~= "table" then
    return tostring(value)
  end
  local parts = {}
  for k, v in pairs(value) do
    parts[#parts + 1] = tostring(k) .. "=" .. tostring(v)
  end
  return "{" .. table.concat(parts, ", ") .. "}"
end

print(dump(point))          -- {x=1, y=2}

local point_mt = {
  __tostring = function(self)
    return ("(%s, %s)"):format(self.x, self.y)
  end,
}
setmetatable(point, point_mt)
print(point)                -- (1, 2)
```

Functions, threads and userdata print addresses the same way. A dedicated
pretty-printer library is usually a better choice than a hand-written `dump`.
