---
layout: pitfall
title: "Multiple return values are truncated"
permalink: /p/L1012/
description: >-
  A call with multiple results is adjusted to a single value unless it is the
  last expression in a list. Extra results are silently discarded, and a call
  in a non-last position loses all but its first value.
runtime:
  - Lua 5.1
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
  - LuaJIT
---

```lua
local function f() return 1, 2, 3 end

local a, b, c = f()
print(a, b, c)        -- 1 2 3

local x = f()         -- only the first result is kept
print(x)              -- 1

local function g()
  return f(), 4       -- f() is not in the last position: truncated to 1
end

print(g())            -- 1 4 (2 and 3 are lost)
```

Wrap a call in parentheses when you want exactly one value:
`local x = (f())`.
