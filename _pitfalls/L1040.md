---
layout: pitfall
title: "Number concatenation without spaces: 1..2 is a syntax error"
permalink: /p/L1040/
description: >-
  The lexer greedily reads `1.` as the start of a number, so `1..2` is parsed
  as the malformed literal `1.` followed by `.2` rather than as `1 .. 2`. Put a
  space or parentheses around `..` whenever a number is on the left.
runtime:
  - Lua 5.1
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
  - LuaJIT
---

```lua
print(1..2)
-- Syntax error: malformed number near '1..2'
```

The concatenation operator `..` is ambiguous with the decimal point of a
number. A space after the number (or an extra pair of parentheses) resolves
it:

```lua
print(1 .. 2)     -- 12
print(1 ..2)      -- 12
print((1)..2)     -- 12
print("a" .. 1)   -- a1: no ambiguity when the left operand is a string
```

Only a number immediately followed by `..` is a problem; for example `1.. 2`
is still malformed because the lexer has already committed to reading `1.`.
