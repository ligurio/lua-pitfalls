---
layout: pitfall
title: "table.concat() requires strings"
permalink: /p/L1009/
description: >-
  Unlike the concatenation operator `..`, `table.concat()` does not convert
  numbers to strings. Passing an array that contains numbers raises a runtime
  error instead of concatenating them.
runtime:
  - Lua 5.1
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
  - LuaJIT
analyzers:
  - emmylua-analyzer
---

```lua
local parts = {"a", "b", 3}

print(table.concat(parts))
-- Runtime error: invalid value (number) at index 3 in table for 'concat'

-- Convert explicitly:
print(table.concat({"a", "b", tostring(3)}))   -- "ab3"
```

Note that `#t` on such a table is only trustworthy for dense arrays; see
[L1004]({{ '/p/L1004/' | relative_url }}).
