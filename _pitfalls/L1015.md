---
layout: pitfall
title: "Floating point precision: `0.1 + 0.2 ~= 0.3`"
permalink: /p/L1015/
description: >-
  Binary floating point cannot represent 0.1 and 0.2 exactly, so the
  expression `0.1 + 0.2` yields 0.30000000000000004 and comparing it with
  0.3 using `==` fails. Compare with an epsilon instead.
runtime:
  - Lua 5.1
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
  - LuaJIT
---

```lua
print(0.1 + 0.2)            -- 0.30000000000000004
print(0.1 + 0.2 == 0.3)     --> false

local function approx(a, b, eps)
  return math.abs(a - b) < (eps or 1e-9)
end

print(approx(0.1 + 0.2, 0.3))  --> true
```

Use an epsilon comparison for money-like math, or round before comparing
when the number of decimals is fixed.
