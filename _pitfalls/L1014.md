---
layout: pitfall
title: "`setfenv`, `loadstring` and `table.getn` removed in Lua 5.2"
permalink: /p/L1014/
description: >-
  `setfenv`, `getfenv`, `loadstring` and `table.getn` existed only in Lua 5.1.
  On Lua 5.2+ they are undefined, so portable code must use `_ENV`, `load` and
  the length operator `#` instead.
runtime:
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
analyzers:
  - luacheck
  - selene
---

```lua
-- Lua 5.1 / LuaJIT:
local f = loadstring("return 1 + 1")

-- Lua 5.2+: attempt to call global 'loadstring' (a nil value)
-- Portable:
local f = load("return 1 + 1")
```

```lua
-- Lua 5.1 only:
local n = table.getn({1, 2, 3})

-- Portable:
local n = # {1, 2, 3}
```

`setfenv`/`getfenv` had no direct replacement; on 5.2+ environment handling
goes through the `_ENV` upvalue. `luacheck` and `selene` flag these as
undefined globals when targeting 5.2+.
