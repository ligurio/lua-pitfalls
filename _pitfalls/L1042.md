---
layout: pitfall
title: "pcall(obj.method, ...) loses self"
permalink: /p/L1042/
description: >-
  Writing `obj.method` produces the function without its receiver. Passing that
  function to `pcall` calls it with the first argument bound to `self`, so a
  method that expects `self` receives a plain argument instead.
runtime:
  - Lua 5.1
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
  - LuaJIT
analyzers:
  - semgrep
---

```lua
local account = { balance = 0 }

function account:deposit(amount)
  self.balance = self.balance + amount
end

local ok, err = pcall(account.deposit, 10)
-- deposit(10): self is the number 10
-- Runtime error: attempt to index a number value (field 'balance')
```

The colon call `account:deposit(10)` is exactly `account.deposit(account, 10)`.
`pcall` does not add the receiver on its own, so pass it explicitly:

```lua
local ok, err = pcall(account.deposit, account, 10)
print(account.balance)  -- 10
```

Alternatively wrap the call in a closure, so the colon syntax is used inside:

```lua
local ok, err = pcall(function()
  account:deposit(10)
end)
```
