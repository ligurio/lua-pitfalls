title: "Assigning to a loop variable does not modify the collection"
permalink: /p/L1044/
description: >-
  In a generic `for k, v in ...` loop the control variables are locals that are
  re-bound on every iteration. Assigning to them only changes the local copy;
  the table being traversed is left untouched. Mutate the table through its key.
runtime:
  - Lua 5.1
  - Lua 5.2
  - Lua 5.3
  - Lua 5.4
  - Lua 5.5
  - LuaJIT
analyzers:

```lua
local prices = { apple = 1, banana = 2 }

for name, price in pairs(prices) do
  price = price * 2          -- rebinds the local 'price'
end

print(prices.apple)          -- 1, the table was not changed
```

`name` and `price` are ordinary local variables. To change the stored value,
write to the table with the key:

```lua
for name, price in pairs(prices) do
  prices[name] = price * 2
end

print(prices.apple)          -- 2
```

The same holds for `for i, v in ipairs(t)` and for the numeric `for i = a, b`
form: assigning `i` does not affect how the loop continues.
