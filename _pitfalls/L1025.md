---
layout: pitfall
title: "math.pow(), math.atan2() and hyperbolic functions removed in Lua 5.4"
permalink: /p/L1025/
description: >-
  Lua 5.3 deprecated `math.pow()`, `math.atan2()`, `math.cosh()`, `math.sinh()`
  and `math.tanh()`; Lua 5.4 removed them. Use `x ^ y` instead of
  `math.pow(x, y)` and `math.atan(y, x)` instead of `math.atan2(y, x)`. The
  hyperbolic functions have no direct standard-library replacement.
runtime:
  - Lua 5.4
  - Lua 5.5
analyzers:
  - luacheck
  - selene
---

```lua
local p = math.pow(2, 10)      -- 1024 (Lua 5.1-5.3)
local a = math.atan2(1, 1)     -- 0.78539816339745 (Lua 5.1-5.3)
local c = math.cosh(1)         -- 1.5430806348152 (Lua 5.1-5.3)
```

```lua
-- Lua 5.4+: attempt to call field 'pow' (a nil value)
```

Portable forms:

```lua
local p = 2 ^ 10
local a = math.atan(1, 1)

-- Hyperbolic functions: implement them with exp() or use an external library
local function cosh(x) return (math.exp(x) + math.exp(-x)) / 2 end
```

`luacheck` and `selene` flag these as undefined fields when targeting 5.4+.
